## Задание на РГР

Разработать на языке Python 3 консольное приложение для определения оценки по дисциплине. 
На вход приложению подается полное название файла с баллами студентов. На выход (в консоль или файл) 
приложение должно вывести список студентов с оценками по дисциплине в соответствии с технологической картой.

Способ запуска: 
```
python main.py <путь к файлу .ods>
```
